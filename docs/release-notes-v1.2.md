## v1.2 更新内容

- 新增「反馈 / 报告问题」入口（主界面按钮）
  - 遇到「眨了不翻 / 太敏感 / 某机型失灵」等问题，可以直接写一句话反馈给作者。
  - 可选勾选「附带诊断信息」，帮助作者定位问题：只含 App 版本、手机型号、检测运行状态（帧率、命中次数、无障碍连接态等）。
  - **绝不**上传：摄像头画面、人脸、任何个人身份信息或反馈以外的内容。
- **没网也能发**：反馈会先保存在本机，联网后自动发送，发送成功后可在「我的反馈」里查看反馈编号。全程不会出现"发送失败"。
- **未同意匿名统计也能反馈**：反馈是你主动发起的，与匿名统计的同意与否互不影响。
- 眨眼翻页主功能与 v1.1 一致，无行为变化。
