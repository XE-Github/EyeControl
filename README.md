# 眨眼控制

用**眨眼**和**闭眼**翻短视频,双手不碰手机也能刷抖音、快手。为行动不便者、双手被占用的场景,以及想解放双手的普通用户而做。

> **隐私优先**:摄像头画面只在你自己手机上处理,用来判断「睁没睁眼」,**不录制、不保存、不上传**。全程本地。

---

## 📥 下载安装

前往 **[Releases](../../releases)** 页面下载最新的 `眨眼控制-vX.X.apk`,传到手机安装即可。

安装提示:

- 手机会提示「未知来源 / 风险应用」——这是所有非应用商店 APK 的正常提示,点「仍要安装 / 继续」即可。
- 若你装过更早的测试版,需**先卸载旧版**再装(签名不同,无法直接覆盖)。

安装后的详细使用步骤见 **[使用说明.md](使用说明.md)**。

## ✋ 怎么用

对着前置摄像头:

| 动作 | 效果 |
|---|---|
| **快速连眨 3 下** | 翻到**下一个**视频(相当于向上滑) |
| **闭眼保持约半秒** | 翻到**上一个**视频(相当于向下滑) |

两个动作走完全不同的判定方式(一个数眨眼次数、一个看闭眼时长),所以**多眨几下永远只会是「下一个」,不会翻反方向**;正常看视频的自然眨眼不会误触发。灵敏度、连眨下数都可在 App 内调。

首次使用需在 App 内依次授权 **摄像头 → 悬浮窗 → 无障碍** 三项,界面从上到下点开即可(图文见使用说明)。

---

## 🔒 隐私

- **全程本地处理**:摄像头画面只喂给手机本地的人脸检测模型算「睁没睁眼」,不录制、不保存、不上传。
- **唯一一次联网**:首次启动会下载一个约 3–4MB 的人脸检测模型文件到 App 内部,仅此一次,只下载、不回传任何画面。之后可断网使用。

## 🛠 想自己编译?

代码即本仓库。开发者构建指南(Android Studio / 命令行编译、模型离线打包、各模块导览)见 **[README-android.md](README-android.md)**。

主要模块:

- `BlinkDetector.kt` — 眨眼算法(EAR + 自适应基线 + AGC + 峰谷检测)。
- `FaceAnalyzer.kt` — CameraX 帧 → MediaPipe FaceLandmarker → 关键点 + 卡顿侦测。
- `CameraService.kt` — 前台服务:常开摄像头 + 悬浮窗 + 把命中转给无障碍。
- `SwipeAccessibilityService.kt` — 无障碍 `dispatchGesture` 竖直滑动。
- `OverlayView.kt` — 悬浮窗状态胶囊 UI。
- `MainActivity.kt` — 三项权限引导 + 设置 + 开始/停止。
